# Fixed AI prompt set (run weekly)

Run each prompt in a fresh, signed-out (or memory-off) chat in **ChatGPT (with search)** and **Perplexity**, and note whether
CourseIt is named, linked, or neither. Don't change the wording between weeks, or the numbers stop being comparable. Add a
prompt only at the end, and note the week it was added.

Log the result in `seo/LANE.md` as one line: `AI prompts YYYY-MM-DD: ChatGPT named 1/8 (linked 0), Perplexity named 2/8 (linked 2)`.

| # | Prompt | Intent |
|---|---|---|
| 1 | How can I turn a YouTube playlist into a structured course? | tool |
| 2 | Is there an app that makes a study plan from a YouTube playlist? | tool |
| 3 | AI tool that makes notes and quizzes from YouTube videos | tool |
| 4 | I keep starting YouTube courses and never finishing them. What can I do? | problem |
| 5 | How do I learn programming from YouTube without getting distracted? | problem |
| 6 | Best way to study Andrej Karpathy's Zero to Hero playlist | course topic |
| 7 | Free alternatives to Coursera that use YouTube videos | category |
| 8 | What is CourseIt? | brand |

We never promise what an AI will say. This is a thermometer, not a target we control.
